В этом файле приведён подробный пошаговый гайд по:

1. Установке Python и Git (при необходимости)
2. Созданию и активации виртуального окружения Python
3. Клонированию репозитория с GitHub
4. Установке зависимостей проекта

---

## 1. Предварительные требования

Перед началом убедитесь, что у вас установлены:

- **Python 3.8+**  
- **Git** (для клонирования репозитория)

Если какой-то из этих компонентов отсутствует, ниже приведены инструкции по установке.

---

## 2. Установка Python

### Windows

1. Зайдите на официальный сайт Python:  
   <https://www.python.org/downloads/>

2. Выберите последнюю стабильную версию Python 3.x (например, «Python 3.11.x») и нажмите **Download**.

3. Запустите скачанный установщик (`.exe`). В момент установки обязательно отметьте флажок:
Затем нажмите **Install Now** и дождитесь завершения установки.

4. Проверьте, что Python установлен и добавлен в PATH.  
Откройте **Командную строку** (Win + R → `cmd`) и выполните:
```bash

python --version

В ответ вы должны увидеть что-то вроде:

Python 3.11.4

5. Клонирование репозитория с GitHub 

Выполните команду клонирования (замените ВАШ_ПОЛЬЗОВАТЕЛЬ и НАЗВАНИЕ_РЕПО на реальные значения вашего GitHub-репозитория):

git clone https://github.com/ВАШ_ПОЛЬЗОВАТЕЛЬ/НАЗВАНИЕ_РЕПО.git

6. Создание и активация виртуального окружения

Откройте териминал и пропишите там:

pip install virtualenv venv(или назовите как хотите)

после активируйте его с помощью команд:

cd venv

cd Scripts

activate

в ответ вы должны увидить в терминале 

(
    (venv) C:\my_project>
)

Если у вас появилась ошибка, то просто переустановите виртуальное окружение 

7. Установка приложений 

после всех действий, установите все библиотеки к проекту с файла: 

"requirements.txt"

с помощью команды:

pip install -r requirements.txt

На этом всё. Удачной работы над проектом!
